10 · 트러블슈팅
막혔던 4가지와 한 줄 해결
#1 · Tailwind v4
@apply가 커스텀 클래스를 모른다

.btn{@apply…} → 다른 곳에서 @apply btn 하면 에러. v4는 @utility btn{…}로 선언

#2 · React
SSR 이미지 404를 onError가 놓친다

하이드레이션 전 실패는 이벤트가 안 온다 → 마운트 시 img.complete && naturalWidth===0 재확인

#3 · shadcn 도입
토큰 이름이 충돌한다

내 --accent/--muted가 shadcn 토큰과 겹쳐 덮어씌워짐 → --orange/--ink-muted로 리네임, primary=네이비

#4 · 캡처
dev 서버는 하이드레이션 전에 찍힌다

문서용 스크린샷은 next build && next start + 헤드리스 Edge --screenshot
